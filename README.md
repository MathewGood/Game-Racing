# Crazy Relay Stadium

`Crazy Relay Stadium`은 웹 브라우저에서 바로 실행하는 코믹 캐주얼 육상 계주 자동 경주 게임입니다. 플레이어는 경기 전에 참가 팀 수, 계주 인원 수, 팀/주자 라인업을 고르고 경기 중에는 선수들의 과장된 능력과 랜덤 이벤트를 관전합니다.

## 실행 방법

별도 빌드 과정이나 서버가 필요 없습니다.

1. 저장소 루트에서 `index.html`을 브라우저로 엽니다.
2. 로컬 서버로 확인하고 싶다면 아래 명령을 실행한 뒤 표시된 주소로 접속합니다.

```bash
python3 -m http.server 8000
```

## 주요 기능

- 참가 팀 수 2~10팀 조정
- 2명, 4명, 6명 계주 모드 지원
- 각 레인의 팀 이름 직접 입력 지원
- 팀 전체 선택 모드와 팀별 주자 직접 선택 모드 지원
- 관중석이 둘러싼 큰 타원형 경기장 트랙에서 각 주자가 400m 한 바퀴씩 달리는 자동 계주 시뮬레이션
- 레인별로 다르게 배치된 출발선과 바통존
- 다음 주자가 자기 팀 바통존에서 대기하다가 바통을 받는 교대 연출
- 3, 2, 1 카운트다운과 출발 총성 후 레이스 시작
- Web Audio 기반 출발음과 경기 중 관중 응원 소리
- 트랙 위 주자는 머리, 몸통, 팔, 다리, 신발이 움직이는 스프라이트 캐릭터로 표시
- 최소 12명 이상의 코믹 주자와 고유 능력
- 관중 함성, 신발끈 풀림, 풍선 난입, 황금 바통 등 랜덤 이벤트
- 실시간 순위, 진행 거리, 현재 주자, 남은 거리, 이벤트 로그 표시
- 결과 화면, MVP 웃긴 순간, 다시하기 기능
