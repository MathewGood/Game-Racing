# Running 100m — Championship Edition

## Running 100m — 육상 시뮬레이션

새 버전은 Electron + Three.js + TypeScript 기반의 100M 관전형 게임입니다.

```bash
npm install
npm start       # Electron 데스크톱 실행
npm run dev     # 브라우저 개발 실행
npm test
npm run build   # macOS/Windows 설치 패키지 생성
```

2~50명의 이름, 남녀 구분, 12가지 경기 스타일을 설정한 뒤 조 편성, 예선, 결선, 시상식 전체 흐름을 진행할 수 있습니다. 물리는 렌더링과 분리된 120Hz 고정 프레임 및 시드 난수로 계산되며, `src/core/`에 속도·조 편성·순위 로직, `src/render/`에 Three.js 경기장, `src/audio/`에 오프라인 관중·경기 사운드, `src/ui/`에 화면 스타일, `src/data/`에 능력치 프리셋이 있습니다.

### 선수 인체 모델

현재는 육상 선수의 피부·얼굴·눈·머리카락·육상복·손발·관절 비율을 직접 구성한 프로시저럴 인체 모델을 사용합니다. 기존 `runner.glb`는 방탄복 Soldier 데모 모델이고 축과 외형이 육상 경기에 맞지 않아 자동 적용 대상에서 제외했습니다.

선수 등록에서 동아시아계·유럽계·아프리카계 외형 프리셋과 버즈컷, 크롭컷, 사이드 파트, 웨이브, 컬리, 아프로, 브레이드, 포니테일, 번, 언더컷을 선택할 수 있습니다. 외형 프리셋은 얼굴 비율·피부 톤·모발 팔레트만 바꾸며 능력치와 경기 결과에는 영향을 주지 않습니다. 개인별 신장·체형·눈동자·수염·헤드밴드·손목 테이프 변형도 레인별로 조합됩니다.

### 선수 모델 교체 방법

기본 선수는 프로시저럴 인체 리그(IK 접지 보행)로 렌더링됩니다. 리깅과 달리기 애니메이션이 포함된 실제 육상 선수 glTF 모델을 아래 경로에 넣으면 자동 감지되어 교체됩니다. 파일이 없거나 Soldier 데모처럼 부적합한 모델이면 기본 인체 모델을 안전하게 사용합니다.

- `src/public/models/runner_m.glb` — 남자 선수
- `src/public/models/runner_f.glb` — 여자 선수 (없으면 runner.glb 공용)

Mixamo 등에서 육상복 캐릭터에 "Running" 또는 "Sprint" 애니메이션을 적용해 glTF/glb로 내보낼 수 있습니다. 클립 이름에 run/sprint/jog가 포함되면 인식하며, 신장 1.85m·발바닥 높이·수평 중심을 자동 보정하고 보폭 속도를 실제 주행 속도와 동기화합니다.

### 실제 스프린트 그래픽

- 6단계 인체 개선: 인체 비율·근육 실루엣 → 얼굴·육상복 → 실제 cadence → 발 접지·상체 균형 → 측면 전용 카메라 → 피니시 린·우승자 강조
- 관절 리깅 선수 모델: 팔꿈치·무릎·발목·손목이 연동되는 프로시저럴 달리기, 스타팅 블록 → 드라이브 → 전력 질주 → 피니시 린 → 감속 조깅
- 캔버스 텍스처 트랙: 레인 라인·레인 번호·10m 구간 표시·스타트/피니시 라인, 스타팅 블록 소품
- 스타디움: 12단 계단식 관중석 + 지붕, 2,600명 컬러 관중 웨이브(InstancedMesh), 야간 조명탑 4기, 스크롤 LED 광고보드, 실시간 타이머·선두 표시 대형 전광판, 밤하늘 별
- 측면 전용 추적 시점: 카메라와 시선의 X좌표를 항상 같게 유지해 선수의 옆모습만 표시하고 뒷모습·정면 컷을 구조적으로 차단
- 피니시 구간은 카메라를 결승선에 고정하고 `1ST` 배지, 우승자 이름·기록 배너, 전광판 `WINNER`를 동시에 표시
- 포토피니시 화이트 플래시, 결선 종료 직후 1위 통과 순간을 실제 재생 시간 약 1초로 자동 슬로모션 리플레이
- 첨부된 실제 경기장 박수·드럼·챈트 WAV와 합성 앰비언스를 혼합하고, 레이스 진행에 따라 함성 크기를 자동 조절
- 메뉴·선수 등록 화면에서 재생되는 오프라인 합성 스포츠 테마 음악, 출발 총성과 발소리
- 남녀 체형 비율·헤어 실루엣·얼굴·배번·신발 앞코로 진행 방향과 선수 구분을 명확하게 표현

### Championship Edition 기능

- 빠른 경기: 별도 설정 없이 기본 8인 결선을 즉시 시작
- 대회 모드: 최대 50명 등록, 조 편성, 예선, 결선, 시상식
- 저장형 환경설정: 성능/균형/시네마틱 그래픽, 전체/관중/음악 음량, 이름표, 모션 감소
- 경기 제어: `ESC` 또는 `P` 키와 HUD 버튼으로 일시정지·재개
- 선수 명단 자동저장과 공식 결과 CSV 내보내기
- 3개 외형 계열, 15개 피부 톤, 10개 헤어스타일과 개인별 체형·액세서리
- 선수마다 출발 후 무작위 시점에 한 번 발동하는 10종 필살기: 사족 말 질주, 거인 보폭, 활공 비행, 로켓 파이어, 돌연 휴식, 미스터리 포션, 스프링 슈즈, 닌자 잔상 대시, 댄스 브레이크, 강제 역풍
- 필살기는 가속·감속·완전 정지를 모두 포함하며 실제 스플릿과 결과에 반영되지만 8초 이내 기록은 허용하지 않음
- 반응시간, 10m 단위 스플릿, 대회 기록(CR), 기록실
- 부정출발 로직 없음: 모든 경기는 정상 스타트로 진행

### 출시 전 필수 자산

코드와 렌더링 파이프라인은 상용 GLB 선수 자산을 받을 준비가 되어 있지만, 저장소의 `runner.glb`는 육상선수가 아닌 Soldier 데모이므로 자동 차단됩니다. 판매 빌드에는 초상권과 상업 이용권이 확보된 스캔 선수 모델, 모션 캡처, 음악·관중음 라이선스 증빙, 앱 아이콘과 스토어 이미지가 필요합니다.
